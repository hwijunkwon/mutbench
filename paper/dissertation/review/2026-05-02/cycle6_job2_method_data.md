# Cycle 6 Job 2 -- Method and Data Appropriateness

Scope: active English chapter files in `paper/dissertation/chapters_en/`, evaluated against Axis 3 and Axis 6 in `cycle6_design_review.md`. This review judges whether the methods and data are appropriate for the dissertation's stated claims. It does not re-run the cycle 4 audits on statistical alternatives, Layer A curation reproducibility, HIV-1 selection, or generalisation scope; those are referenced where relevant.

## 1. Axis 3 Results: Method Appropriateness

| Check | Verdict | Evidence | Rationale |
|---|---|---|---|
| M1. Is omega/ANOVA the right estimand for "pathogen-dependent optimality"? | Qualified appropriate | Ch3 defines a 20 scoring x 14 family x 11 pathogen ANOVA and reports scoring x pathogen omega as the primary effect; Ch4/Ch5 repeatedly distinguish evaluation-level omega 0.296 from cell-level 0.234 and category-level 0.103. | Omega directly answers a variance-decomposition version of the question: whether scoring performance varies systematically by pathogen. It does not by itself identify an actionable optimal rule for a new pathogen, and it compresses rank/order, winner identity, and magnitude into one component. The manuscript mostly handles this by using "modeled component" language and by pairing omega with oracle gap, per-pathogen winners, LOPO, and feature analysis. Best phrasing: omega is the primary estimand for retrospective pathogen-dependence, not a complete estimand for deployable pathogen-specific optimality. |
| M2. Is Friedman used for the correct rank-level question? | Appropriate but low-information | Ch3 defines Friedman as comparing top k=20 scoring x family combinations across 11 pathogen blocks; Ch4 reports Friedman chi-square 7.69, p=0.990, and says no single combination is reliably superior across all pathogens. Ch5 explicitly calls the result uninformative rather than a strict null. | Friedman answers: do the selected combinations have consistent rank differences across pathogen blocks? It does not test the ANOVA interaction and does not prove all methods are equivalent. The reported interpretation is largely correct: p=0.990 is a failure to find a universally superior rank pattern at n=11, consistent with but not independent proof of pathogen-dependent optimality. |
| M3. Is LOPO interpreted correctly as corroborative evidence vs standalone proof? | Calibrated | Ch4 states LOPO yielded 0/11 exact matches, mean generalization MCC 0.032, oracle-vs-generalized gap 0.265, and a random-combination permutation p about 0.25-0.28; it explicitly says LOPO is corroboration, not independent positive evidence. Ch5 repeats that LOPO is null-consistent. | This is the right use. LOPO failure is compatible with pathogen dependence and useful for defense because it shows the best training-set combination does not transfer. But because the permutation is null-consistent and the same data matrix is reused, it cannot stand alone as proof. The current wording avoids the major overclaim. |
| M4. Are bootstrap and cluster-bootstrap units defensible for the uncertainty claim? | Defensible but limited | Stage 1 bootstraps SARS-CoV-2 functional regions, not individual positions. Stage 2 uses pathogen-cluster bootstrap for the interaction, plus wild-cluster and phylogenetic block bootstraps. Ch3/Ch5 disclose n=11 anti-conservatism and the lack of delete-one jackknife. | For a cross-pathogen claim, "pathogen" is the defensible resampling unit because per-evaluation rows share MSA, labels, and detector variants. Per-row bootstrap would be inappropriate for biological uncertainty. The limitation is that 11 pathogens and 8 family blocks are still small, so intervals support direction/scale rather than precise endpoints. Stage 1's region bootstrap is also appropriate for region-definition uncertainty, not for Stage 2 cross-pathogen inference. |
| M5. Do Bayesian checks clarify robustness, or create unnecessary method sprawl? | Useful but near the edge of sprawl | Ch3 reports Bayesian partial-pooling and Bayesian factor-analysis checks; Ch5 summarizes five inferential frames and a later Bayesian adaptive-weighting failure. Cycle 4 F already found further Bayesian model averaging unlikely to change the conclusion. | The Bayesian checks clarify one real vulnerability: small-cluster inference around omega. They are useful when presented as triangulation of the same interaction lower bound. The risk is method sprawl: multiple Bayesian variants, mixed models, ART, wild-cluster, and adaptive-weighting Bayes can blur which analysis is primary. The dissertation should keep the hierarchy explicit: primary ANOVA/omega, small-cluster robustness checks, adaptive-weighting negative result as separate operational evidence. |
| M6. Would a simpler blocked-permutation result be more defense-useful than additional complex models? | Yes | Ch3 includes Stage 1 label/circular permutation and sign-flip tests for nested-LOPO, but no simple blocked-permutation ANOVA for the headline interaction. Cycle 4 F recommended a pathogen-blocked permutation ANOVA as the highest-value addition and discouraged more complex alternatives. | A blocked permutation would be more explainable in defense than another mixed/Bayesian model: "under a pathogen-preserving null, how often is the interaction this large?" It would not replace omega, but it would give a transparent randomization answer. This review should not re-do cycle 4 F; the actionable conclusion is to reference that report and avoid adding heavier models before adding the simple blocked-permutation if time permits. |
| M7. Are all analyses reported in Ch4 sufficiently specified in Ch3? | Minor missing | Ch3 specifies ANOVA, LOPO, nested-LOPO, Friedman, BCa/cluster/wild/phylogenetic/bootstrap, Bayesian factor analysis, Stage 3 ablation, RF, and escape validation. Some later Ch4 audit paragraphs cite scripts/CSVs and include detailed rules in Results, especially Wave 1-5, P5/P6 nulls, Layer A', and Cycle 7B adaptive weighting. | The core Chapter 4 analyses are well specified in Ch3. The late-cycle audit program is sometimes specified where it is reported rather than fully pre-specified in Methods, which makes the methods chapter trail the results chapter. For defense, this is a minor rather than major gap because scripts/CSVs and pre-registration language are present, but Ch3 should contain a compact "late robustness audit protocols" table or explicitly label them as post-main-design audits. |

## 2. Axis 6 Results: Data Appropriateness

| Check | Verdict | Evidence | Rationale |
|---|---|---|---|
| D1. Is the 11-pathogen panel adequate for the stated RNA-virus single-position scope? | Limited but defensible | Ch3 lists 11 RNA viruses across 8 ICTV families, multiple transmission routes, alignment lengths 261-1,330 AA, and substitution-rate range roughly 4e-4 to 4.5e-3. Ch5 states the panel is deliberately diverse but non-exhaustive and fixed-effect inference applies to these 11 pathogens. Cycle 4 H already flagged the missing candidate-exclusion ledger. | The panel is adequate for a bounded retrospective benchmark of selected RNA-virus surface glycoproteins in the single-position regime. It is not adequate for a general claim about all RNA viruses, all surface proteins, or deployable adaptive selection. The current text mostly uses the right bounded scope; the missing piece is a concise candidate target ledger rather than more statistical defense. |
| D2. Is the 12-pathogen Stage 3 panel clearly separated from 11-pathogen claims? | Mostly clear | Ch3 says Stage 1 and 2 are the main 11-pathogen design and Stage 3 optionally extends to 12 by adding Zika when feature power benefits; Ch4 table captions often say "core 11 + Zika" and note core-11 restrictions. | The separation is substantially clear, but the manuscript is demanding because Stage 3, nested-LOPO, Wave audits, and feature-ablation results move between 11 and 12 pathogens. This is appropriate if every table caption keeps the denominator explicit. Defense phrasing should avoid saying "the 11-pathogen benchmark" when quoting 12-fold feature-ablation numbers. |
| D3. Are sequence sources, filters, deduplication, alignment, and date scope verifiable from methods? | Partial to complete | Ch3 provides GenBank query principles, complete-CDS/lab/partial filters, query dates in 2024-11 to 2024-12, accession/reference table, exact-dedup SHA-256 logic, no near-duplicate clustering, MAFFT version/mode, truncation to minimum length, provenance CSV paths, and no raw GISAID redistribution. | For a dissertation methods chapter, sequence provenance is largely verifiable. | D4. Is Layer A appropriate for positive labels despite heterogeneous evidence types? | Defensible with caveats | Ch3 defines Layer A as literature-curated adaptive/diversifying positions with pathogen-specific mechanisms; Ch5 discloses heterogeneity, frequency coupling, HCV/Norovirus/HVR/epochal caveats, and subset sensitivity. Cycle 4 B found Layer A defensible as a transparent frozen artifact but not as a formally reproducible curation process. | Layer A is fit for the claim it supports: a practical retrospective benchmark against published adaptive/diversifying position evidence. It is not a single biological construct and should not be described as uniform convergent-evolution ground truth. Current neutral terminology mostly works if the thesis consistently says "adaptive/diversifying" or "Layer A positives" rather than implying residue-equivalent experimental proof. |
| D5. Are Layer B and Layer C used only for claims they can support? | Calibrated | Ch3 says MCC uses Layer A, Layer B is separately tracked via constrained FPR, and Layer C supports DMS F1 for six pathogens. Ch4 reports Layer A vs C scoring divergence and says DMS/evolution capture non-identical aspects. | This is appropriately separated. Layer B is not overused as a universal negative truth beyond constrained FPR, and Layer C is not merged into a universal label. The main caution is interpretive: Layer C results support functional-impact comparison where available, not validation of all 11 pathogen labels. The manuscript usually states this clearly. |
| D6. Is HIV-1 external validation independent and strong enough for the practical anchor role? | Strong for anchor, limited for generalization | Ch4 reports HIV-1 7.19x enrichment, Bonferroni survival, 37/45 escape positions disjoint from Layer A, 82% disjoint, and novel-only enrichment remaining significant. H3N2 is demoted to self-consistency and SARS-CoV-2 to exploratory. Cycle 4 G found no sustained cherry-pick reversal but a medium presentation vulnerability around "availability." | HIV-1 is strong enough to serve as the practical anchor because it satisfies both significance and Layer A independence better than the other escape panels. It is not strong enough to make the practical-value claim general across all 11 pathogens. The current tiered framing is appropriate; retain "anchored by HIV-1" and avoid wording that treats all three escape panels as equally external. |
| D7. Are missing alternative datasets and unavailable validation panels acknowledged? | Explicit but still incomplete | Ch4 lists why eight pathogens lack escape validation: coarse granularity, small sample size, Layer A confounding, or mechanism mismatch. Ch5 limitations cover DMS incompleteness, GISAID bias, ESM-2 overlap, lack of external reproduction, no HMM screen, no single-mode MAFFT sensitivity, and future panel expansion. Cycle 4 H still recommends a target-exclusion ledger. | The manuscript does acknowledge the main missing data classes. The remaining gap is not hidden limitations but navigability: excluded targets, alternative escape resources, and future validation panels are dispersed across Ch4/Ch5. A compact "not used and why" table would make the data appropriateness easier to defend without re-opening curation reproducibility. |

## 3. Top 3 Cross-Axis Gaps and Suggestions

1. **Primary estimand vs deployable optimality.** Omega is appropriate for retrospective interaction, but not for predicting the best method on a new pathogen. Add one sentence near the contribution summary: "The omega interaction estimates retrospective method-by-pathogen dependence; deployable pathogen-specific selection remains unsupported until expanded-panel LOPO/callability succeeds."

2. **Small-cluster robustness is over-instrumented but lacks the simplest randomization answer.** Keep the Bayesian/mixed/wild-cluster checks as supporting triangulation, but do not add more complex models. If time permits, implement or cite the cycle 4 F recommendation: a pathogen-blocked permutation ANOVA with the same omega statistic and a plainly stated exchangeability rule.

3. **Data scope is defensible but scattered.** The panel, Layer A heterogeneity, missing escape panels, and 11-vs-12 distinction are each disclosed, but a committee reader must assemble them from multiple sections. Add one compact Methods/Appendix table: included main targets, Stage 3-only targets, excluded candidates, sequence count, label feasibility, external validation availability, and exclusion reason.

## 4. Verdict Summary

Method appropriateness is **medium-to-strong**. The main ANOVA/omega estimand is well matched to the retrospective pathogen-dependence claim, and LOPO/Friedman are now interpreted as corroborative or null-consistent rather than standalone proof. The main weakness is not statistical fragility--cycle 4 F found no high-risk alternative-model reversal--but defense clarity: the analysis stack is complex, and a simple blocked-permutation result would communicate the null model better than further model additions.

Data appropriateness is **medium**. The 11-pathogen panel, Layer A positives, Layer B/C separation, and HIV-1 anchor are fit for a bounded RNA-virus, surface-glycoprotein, single-position retrospective benchmark. They are not sufficient for a general all-RNA-virus claim or a deployable adaptive selector. Cycle 4 B/G/H already cover the deeper curation reproducibility, HIV-1 presentation, and generalisation issues; this review's data verdict is that the current datasets are appropriate only because the dissertation now mostly bounds the claims to what those datasets can support.
