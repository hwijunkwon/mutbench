## 2. Top 3 generalisation-attack vectors

1. **No candidate-exclusion ledger for RNA-virus surface proteins.** The manuscript defends why the 11 selected pathogens are diverse, and it documents Zika plus later expansion/skipped targets, but it does not show a systematic candidate universe. A committee can ask why particular omitted alphavirus, bunyavirus, paramyxovirus, filovirus, or additional flavivirus targets were not in the main panel.

2. **Retrovirus boundary is internally ambiguous.** HIV-1 is included and is a major practical anchor, so a blanket “retroviruses excluded” statement would be false. The manuscript needs a precise line: HIV-1 Env is included as the only retroviral surface glycoprotein case; other retroviruses and reverse-transcribing viruses are not validated.

3. **Indel scope is easy to challenge.** “Point substitutions only” conflicts superficially with `freq_with_indel` and `entropy_with_indel`. The current text can be defended as per-position gap-aware scoring, but it does not explicitly say MutBench does not evaluate inserted/deleted segment events, frameshifts, recombination, or coordinated multi-residue events.

## 3. Recommended manuscript additions

1. Add a one-page “candidate target ledger” in Methods or Appendix: included, supplementary-feature-only, skipped, and not attempted targets; columns for virus family, protein, sequence count, Layer A feasibility, DMS/escape availability, and exclusion reason.

2. Add one scope sentence: “HIV-1 Env is the only retroviral target evaluated; no conclusion is made for other retroviruses, reverse-transcribing DNA/RNA viruses, bacterial pathogens, eukaryotic pathogens, or non-viral systems.”

3. Add a boundary note distinguishing “gap-aware per-column scores” from true indel/multi-residue detection: the current benchmark ranks reference-aligned positions only and does not model inserted segments, deletion-length events, recombination, frameshifts, or epistatic event sets.

## 4. Verdict

Scope discipline: **medium**. The dissertation is careful about the main RNA-virus, single-position, region-detection claim; HBV is correctly interpreted as a boundary check; and the DMS/VEP distinction is well defended. The remaining weakness is not overclaiming, but incomplete boundary documentation for omitted RNA-virus targets, non-HIV retroviruses, rate-envelope extrapolation, and indel/event-level exclusions.
