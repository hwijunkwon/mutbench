# MutBench 벤치마크 프레임워크 설계

---

## 아키텍처

3계층 설계:

```
┌─────────────────────────────────────────────┐
│  Layer 3: 평가 (Evaluation)                  │
│  precision, recall, F1, enrichment, dN/dS    │
│  파라미터 민감도 스윕, 시각화                   │
├─────────────────────────────────────────────┤
│  Layer 2: 방법 (Methods)                     │
│  MutClust v1/v2a/v2b/v2c                    │
│  Shannon entropy, Frequency, Sliding window  │
├─────────────────────────────────────────────┤
│  Layer 1: Ground Truth                       │
│  DMS 실험 데이터 → 기능적 위치 라벨            │
│  좌표 변환 (AA ↔ 뉴클레오타이드)               │
└─────────────────────────────────────────────┘
```

---

## Ground Truth 생성 파이프라인

```
Bloom lab DMS CSV
    ↓ dms_loader.py
위치별 fitness 점수 (AA)
    ↓ get_functional_positions(threshold_percentile)
기능적 AA 위치 집합
    ↓ coord_mapper.py (AA → nucleotide)
기능적 뉴클레오타이드 위치 집합
    ↓ labeler.py
이진 라벨 배열 [0, 0, 1, 1, 1, 0, ...]
```

**DMS 데이터 출처**: `jbloomlab/SARS2-mut-fitness` (aamut_fitness_all.csv)

**기능적 위치 기준**:
- DMS fitness 절대값 상위 N% (기본: 80th percentile)
- 알려진 기능 부위: RBD (319-541), Furin cleavage (681-685), Fusion peptide (816-833)

## 비교 방법

### MutClust 변이체

| 변이체 | 인터페이스 | 기본 파라미터 |
|--------|-----------|-------------|
| v1-original | `mutclust(hscores, gamma, d, minpts)` → clusters | gamma=10, d=3, minpts=5 |
| v2a-bugfix | 동일 (expand_cluster 수정) | 동일 |
| v2b-bugfix+dnds | 동일 + dN/dS 후처리 | 동일 |
| v2c-full | 동일 (벡터화+seed) | 동일 |

### 베이스라인

| 방법 | 인터페이스 | 기본 파라미터 |
|------|-----------|-------------|
| Shannon entropy | `detect_hotspots(counts, threshold_pct, gap)` | threshold_pct=10, gap=2 |
| Frequency-based | `detect_hotspots(hscores, threshold_pct, gap)` | threshold_pct=10, gap=2 |
| Sliding window | `detect_hotspots(hscores, window_size, threshold_pct, gap)` | window=20, pct=10, gap=2 |

모든 방법은 동일한 출력 형식: `list[dict]` with keys `start`, `end`, `positions`

## 평가 지표

### 위치 수준 (Position-level)

- **Precision**: |detected ∩ ground_truth| / |detected|
- **Recall**: |detected ∩ ground_truth| / |ground_truth|
- **F1**: 2 × (precision × recall) / (precision + recall)
- **Enrichment ratio**: (기능 위치 비율 in 핫스팟) / (기능 위치 비율 in 전체 게놈)
- **dN/dS enrichment**: 탐지된 클러스터의 평균 dN/dS

### 파라미터 민감도

64개 조합 스윕:
- gamma ∈ {5, 10, 15, 20}
- d ∈ {2, 3, 4, 5}
- minpts ∈ {3, 5, 7, 10}

## 향후 확장 계획

### hotspot-score (계획됨)

MOSD의 cluster-score에서 영감받은 통합 평가 지표:

```
hotspot-score = (Recall_known + Precision_simulated + Stability_bootstrap) / 3
```

- Recall_known: 알려진 기능적 변이(D614G, E484K 등) 포착율
- Precision_simulated: 시뮬레이션 ground truth에서의 정밀도
- Stability_bootstrap: 서열 서브샘플링 시 핫스팟 재현율

### 7가지 벤치마크 요인 (계획됨)

MOSD의 9가지 벤치마크 요인에서 영감:

| MOSD 요인 | MutBench 대응 요인 |
|-----------|-------------------|
| Sample size | 서열 수 (100~200K) |
| Feature selection | 게놈 크기 (2kb~200kb) |
| Preprocessing | 정렬 품질 (MAFFT vs MUSCLE) |
| Noise | 서열 오류율 (0~10%) |
| Class balance | 계통 균형 |
| Number of classes | 계통 수 |
| Cancer subtype | 병원체 유형 |
