## 1. expand_cluster 감쇠 공식 수정

**파일**: `tools/mutclust/mutclust_algo/core.py:55`

### 문제

원본의 `_expand_cluster`에서 클러스터 확장 시 `current_deps`를 루프마다 누적 감산:

```python
# 원본 (v1-original)
current_deps = current_deps - (deps_ccm - distance) / d
```

distance가 증가하면서 `(deps_ccm - distance)` 자체도 감소하므로, 이중으로 줄어드는 효과가 발생.
H=1.0 (deps_ccm=10)인 CCM 시드에서 이론적으로 ~7-10개 위치를 확장해야 하지만, 실제로는 2-3개에서 조기 종료.
범위 손실 71-95%.

### 수정

논문의 의도대로 단일 단계 감쇠 공식으로 변경:

```python
# 수정 (v2a-bugfix 이후)
current_deps = deps_ccm - distance / d
```

`deps_ccm`에서 `distance/d`만큼만 감소. 시드에서 멀어질수록 선형적으로 탐색 범위 축소.

### 영향

| 지표 | v1-original | v2a-bugfix |
|------|------------|------------|
| 탐지 위치 수 | 632 | 636 (+0.6%) |
| 클러스터 수 | 30 | 29 (-1) |
| F1 | 0.917 | 0.917 |

소폭 개선. 클러스터 병합으로 인해 하나 줄었지만 총 탐지 위치는 증가.

## 2. H-score 계산 벡터화

**파일**: `tools/mutclust/hscore/core.py:48-68`

### 문제

`compute_hscores_from_alignment()`이 O(N×L) 이중 Python 루프:
- 외부: L개 위치
- 내부: N개 서열

200,000개 서열 × 30,000nt 게놈에서 극도로 느림.

### 수정

numpy 배열 연산으로 전면 교체:

```python
# 서열을 2D 정수 배열로 변환 (N×L)
seq_matrix = np.array([[nuc_to_idx.get(c.upper(), -1) for c in seq] for seq in alignment])

# 위치별 뉴클레오타이드 카운트 (L×4)
counts = np.zeros((seq_len, 4), dtype=int)
for idx in range(4):
    counts[:, idx] = np.sum(seq_matrix == idx, axis=0)

# P, E, H 벡터 연산
ratios = counts / totals
P = 1.0 - ref_ratios
H = np.log2(P * np.abs(E) * 100 + 1)
```

### 영향

- 결과 동일 (수치 회귀 테스트 통과)
- 대규모 정렬에서 100배+ 속도 향상 예상

## 3. Bootstrap 재현성

**파일**: `tools/mutclust/bootstrap/core.py`

### 문제

`bootstrap_hotspot_test()`에 seed 파라미터 없음 → 실행할 때마다 다른 p-value.
벤치마크 재현 불가.

### 수정

```python
def bootstrap_hotspot_test(hscores, start, end, n_iter=1000, seed=None):
    rng = np.random.default_rng(seed)
    # ...
    rand_starts = rng.integers(0, genome_size - region_size, size=n_iter)
```

`np.random.default_rng(seed)` 사용으로 동일 seed → 동일 결과 보장.
`bootstrap_all_hotspots()`에도 seed 전파.

## 4. dN/dS 주석 레이어

**파일**: `tools/mutclust/dnds_annotation/core.py`

### 설계 결정

dN/dS를 H-score 계산에 직접 반영하지 않고, **후처리 주석**으로 구현.
이유: 탐지(detection)와 해석(interpretation)을 분리하여 각각 독립적으로 평가 가능.

### 주요 함수

| 함수 | 역할 |
|------|------|
| `translate_codon(codon)` | 코돈 → 아미노산 번역 (BioPython 표준 코돈표) |
| `classify_mutation(ref, mut, pos)` | 동의/비동의 변이 분류 |
| `compute_cluster_dnds(nonsyn, syn, len)` | Nei-Gojobori 간소화 dN/dS |
| `annotate_clusters(clusters, ref, muts)` | 클러스터 목록에 dN/dS 주석 추가 |

### Nei-Gojobori 간소화

가능한 사이트 비율: 비동의 75%, 동의 25% (근사치)

```
dN/dS = (nonsyn_count / possible_N) / (syn_count / possible_S)
      = (nonsyn_count / (L×3×0.75)) / (syn_count / (L×3×0.25))
```

- dN/dS > 1: 양의 선택 (기능적으로 중요한 변이 축적)
- dN/dS = 1: 중립 진화
- dN/dS < 1: 음의 (정화) 선택
